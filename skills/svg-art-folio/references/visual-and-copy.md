# Visual and copy decisions

Use the supplied image as the authority for the canvas. Separate artwork fidelity from interface styling. The image determines composition, proportions, palette, silhouette, occlusion, material cues, and important details. The surrounding folio may borrow rhythm, paper, type, color, and ornament from the subject, but should be redesigned for each new subject.

Keep all explanatory labels, quotes, stage names, and controls outside the drawing canvas. Join title, quote, stage copy, and footer into one visual voice. Short title-like phrases generally omit a final full stop; prose keeps punctuation where it improves reading. Use official character text only when identity and wording are reliable; otherwise write original themed copy and record uncertainty in the delivery notes.

Prefer a restrained hierarchy: one title scale, one display face, one reading face, one accent color, and a small number of line motifs. Decorative strokes should guide grouping and rhythm. Avoid empty UI filler, generic AI-sounding captions, and elements that compete with the reference artwork.
